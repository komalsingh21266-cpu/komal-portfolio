KOMAL SINGH PORTFOLIO
=====================

Files:
- index.html: website structure/content
- style.css: teal-and-white responsive styling
- script.js: mobile menu, dark mode, active navigation, footer year
- assets/komal-photo.png: profile photo prepared for the hero section
- assets/resume.pdf: add your resume here using this exact filename

Before publishing:
1. Replace YOUR_EMAIL@example.com in index.html with your real email.
2. Replace placeholder GitHub profile/repository links with your real URLs.
3. Add your resume as assets/resume.pdf.
4. Check project metrics and update them only to your verified results.
5. Project dashboard illustrations are mockups; replace with actual project screenshots when available.

Open the folder in VS Code and launch index.html with Live Server.
